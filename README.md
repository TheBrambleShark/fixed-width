# Serde.FixedWidth

A fixed-width format serializer/deserializer for .NET using [Serde](https://github.com/serdedotnet/serde).

## Status

This project is in early development. The repository structure is set up but implementation is not yet started.

## Building

```bash
dotnet build
```

## Testing

```bash
dotnet test
```

## Benchmarking

```bash
dotnet run --project bench -c Release
```
